Tu Hoja de Ruta en Power Query

Sigue estos pasos para transformar el caos en un modelo de datos impecable.

1

Limpiar Espacios Fantasmas

Muchos registros tienen espacios al principio, al final o caracteres no imprimibles. Selecciona las columnas de texto (Cliente, Vendedor, Producto).

Español
Transformar → Formato → Recortar y luego Limpiar
English
Transform → Format → Trim and then Clean
2

Reemplazo de Caracteres Corruptos

El sistema viejo reemplazó letras por números y símbolos. Usa la herramienta de reemplazo de valores en las columnas afectadas.

Sustituciones necesarias: @ → a 3 → e 0 → o # → (dejar en blanco)

Español
Clic derecho en la columna → Reemplazar los valores...
English
Right-click on column → Replace Values...
3

Normalización de Nombres (Mayúsculas/Minúsculas)

Los nombres de clientes y vendedores parecen estar gritando o mal escritos. Dales un formato profesional (Ej: "jUAn PErEz" → "Juan Perez").

Español
Transformar → Formato → Poner En Mayúsculas Cada Palabra
English
Transform → Format → Capitalize Each Word
4

Separación de Entidades (Fecha y Hora)

La columna FECHA_HORA contiene dos datos distintos. Para un buen modelo estrella (Time Intelligence), debes separar la Fecha de la Hora.

Español
Seleccionar FECHA_HORA → Dividir columna → Por delimitador (Espacio)
English
Select FECHA_HORA → Split Column → By Delimiter (Space)
5

Modelado de Tipos de Datos

Asegúrate de que el motor de Power BI entienda qué es texto y qué es matemáticas para poder sumar tus ventas.

  • Español
  • CANTIDAD → Número entero
  • PRECIO_DOP → Número decimal fijo / Moneda
  • FECHA → Fecha
  • English
  • CANTIDAD → Whole Number
  • PRECIO_DOP → Fixed Decimal Number
  • FECHA → Date
